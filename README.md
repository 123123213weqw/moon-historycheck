# Moon HistoryCheck

An independent MoonBit implementation of bounded linearizability checking for concurrent operation histories. It checks the supplied finite observation against a sequential model; it does not prove all executions of a system correct.

Owner: `123123213weqw`. This new project is separate from FindCore and does not inherit its code or commit counts.

The implementation contract is developed through real commits: strict histories and models, precedence-aware search, independently checked witnesses, safe partitioning and counterexample reduction. Completed capabilities and their validation are recorded at release.
